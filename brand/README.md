# Eulearn — Brand Assets

A digital whiteboard app for the classroom. Name = **Euler** (mathematician) + **learn**.

## Folder contents

| Folder | What's inside |
|--------|---------------|
| `icon/` | App icon — SVG master + PNGs (512, 256, 192, 180, 64, 48, 32, 16 px) |
| `wordmark/` | "eulearn" logotype — SVG (outlined) + PNG, in teal / white / slate |
| `lockup/` | Horizontal lockup (icon + wordmark) — SVG + PNG, light & dark |
| `favicon/` | `favicon.ico` (16/32/48 bundled) for browser tabs |
| `fonts/` | Full Quicksand family (see below) + license |

## Typography

**Quicksand** by Andrew Paglinawan — open source, SIL Open Font License (`fonts/OFL.txt`).
Free for commercial use (apps, web, print); no attribution required in-product.

Included weights (`fonts/`):
- `Quicksand-Light.ttf` (300)
- `Quicksand-Regular.ttf` (400)
- `Quicksand-Medium.ttf` (500)
- `Quicksand-SemiBold.ttf` (600)
- `Quicksand-Bold.ttf` (700) — used for the wordmark
- `Quicksand-VariableFont_wght.ttf` (variable, 300–700)

The static weights were instanced from the official Google Fonts variable font.
The wordmark SVGs are converted to outlines, so they render identically without the font installed.

## Design notes

- The icon's "e" is a **logarithmic spiral tapering by φ (the golden ratio, ~1.618)** across its
  sweep — a subtle mathematical nod — drawn on a gridded whiteboard with a marker finishing the stroke.
- The whiteboard panel is a concentric rounded rectangle, equal margin on all four sides.
